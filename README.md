👑 INFORMACIÓN DEL PROYECTO

Nombre: DARK FF V1
Desarrollador: @Axel XIT
Año de creación: 2026
Plataforma: Discord
Lenguaje: JavaScript / Node.js
Base de datos: JSON
Hosting: Railway

DARK FF V1 es un bot multifunción desarrollado para ofrecer herramientas de moderación, seguridad, entretenimiento, economía, música, estadísticas, tickets, IA y administración desde un solo bot.

El proyecto está diseñado para poder crecer continuamente y añadir nuevos sistemas y comandos.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 ¿PARA QUÉ SIRVE DARK FF V1?

DARK FF V1 sirve para administrar y mejorar servidores de Discord sin necesidad de utilizar diferentes bots para cada función.

Con DARK FF V1 puedes:

- 🛡️ Moderar usuarios.
- 🔐 Proteger el servidor.
- 🤖 Automatizar la moderación.
- 📝 Registrar eventos.
- 🎫 Crear sistemas de tickets.
- 💰 Crear una economía.
- 🛒 Crear una tienda.
- ⭐ Subir niveles mediante XP.
- 🏆 Crear logros.
- 🎁 Entregar recompensas.
- 🎮 Jugar minijuegos.
- 😂 Utilizar comandos de diversión.
- 🧠 Utilizar herramientas de IA.
- 💻 Utilizar herramientas de programación.

⚙️ INSTALACIÓN

Instalar dependencias:

npm install

Crear el archivo:

.env

Configurar:

TOKEN=TU_TOKEN
CLIENT_ID=ID_DEL_BOT
GUILD_ID=ID_DEL_SERVIDOR
OWNER_ID=ID_DEL_OWNER
PORT=3000

Iniciar:

npm start

⚙️ ¿CÓMO FUNCIONA DARK?
REMD funciona con tecnología discord.js v14 + Distube + IA. 
1. Invitas al bot a tu servidor con permisos de Admin
2. Configuras con / los módulos que quieras: bienvenidas, anti-spam, música
3. Automatiza todo. DARK se encarga de moderar, dar la bienvenida, subir niveles y reproducir música mientras tú administras.
4. Escala. Cada servidor tiene su propia configuración guardada en base de datos.

Cero lag. Cero complicaciones.
